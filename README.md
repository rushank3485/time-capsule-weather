# ⛅ Zenith · Ambient Weather Intelligence

> A glassmorphic atmospheric dashboard providing real-time climatic indicators, dynamic day/night visuals, air quality index, and multi-day meteorological forecasts.

![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=flat-square)
![Stack: HTML5/CSS3/ES6](https://img.shields.io/badge/Stack-Vanilla_JS-yellow.svg?style=flat-square)
![Deploy: Vercel](https://img.shields.io/badge/Deploy-Vercel-black?style=flat-square&logo=vercel)

---

## ⚡ Highlights

- **Dynamic Atmospheric UI:** Ambient lighting and conditions adapt based on location heuristics.
- **Micro-Metrics Grid:** Tracks Wind velocity, Relative Humidity, Air Quality Index (AQI), and Atmospheric Visibility.
- **5-Day Extended Horizon:** High/Low projections with responsive card layout.
- **No Heavy Bundler Dependencies:** Ultra-fast, zero-overhead static client architecture.
